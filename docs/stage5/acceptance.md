# Stage 5 T11–T12 acceptance

This record distinguishes source coverage, local automated runs, and failure drills. A successful unit test or an HTTP page load is not described as a full end-to-end pass.

## Isolated end-to-end entry point

From the repository root, start the isolated local stack using the instructions in [deployment.md](deployment.md), then run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File backend/scripts/e2e-stage5.ps1
```

The script is ASCII-only for Windows PowerShell 5.1. It rejects non-loopback URLs, targets only the explicitly named `stage5-smoke-20260924` Compose project by default, creates new prefixed users, generates an 8-second synthetic video, and soft-deletes only that video in `finally`. Generated passwords are never printed. Synthetic identities, report, notification, and audit rows remain in the isolated database so the audit trail is preserved; no existing account or media is selected for mutation.

The script covers registration, CSRF-protected login, refresh rotation, profile update, category-backed upload, real Worker/FFmpeg transcode, MinIO/HLS/cover reads, public discovery and creator sharing, follow/like/favorite, comment request replay, reply notifications, read receipt, wall-clock watch credit, duplicate heartbeat, resume position, analytics, explicit day-rank rebuild, report authorization, admin assignment/resolution, hide/restore audit, browser UI interaction, logout, and old-token rejection.

The Playwright run uses `frontend/playwright.stage5.config.ts`, has no `webServer`, and therefore tests the real Nginx/Go/MinIO stack supplied by the script. The ordinary mocked frontend E2E suite remains separate.

The isolated stack was healthy at the end of the run (API, frontend, Kafka, MySQL, MinIO, and Redis healthy; Worker running). All tests that used `-SkipBrowser` are API/fault drills only and are not counted as browser acceptance; the non-skipped main run supplies the real browser result.

T11 local acceptance evidence covers the tested core flow and listed recovery drills, including an observed Outbox failure record, second claim, recovery publish, and cleared error. `attempts` is a claim counter, not a broker delivery count. T12 is locally complete: the pinned k6 runner passed smoke, 21 repeated baseline, 9 stress, and 3 isolated media-read result rows. The documented Redis-unavailable fallback is not a synthetic “cache disabled” switch; category fallback has an approximately 2-second P95 and is a known latency cost. HLS evidence is one small local segment only. Results are not a production capacity claim; see [performance.md](performance.md) for measurements, raw files and limitations.
