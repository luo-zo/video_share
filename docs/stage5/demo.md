# Stage 5 演示流程（约 6 分钟）

此流程使用本地隔离 Compose，不需要任何仓库内置默认密码。演示前准备：按 [deployment.md](deployment.md) 启动 `stage5-smoke-*`；访问 `http://127.0.0.1:15173`；自行注册一个演示创作者和观众账号，并按文档的显式 CLI 管理员授予流程准备单独的管理员账号。不要把真实密码或 token 粘进文档、终端截图或演示录像。

1. **登录与会话（45 秒）**：打开小黑猫登录页，使用创作者账号登录，展示刷新页面后仍保持登录；到设置页改昵称/简介，说明 refresh Cookie 为 HttpOnly、CSRF 与 Origin 由服务端校验。
2. **投稿与播放（75 秒）**：用已准备的短 MP4 投稿，选择分类/标签，等待真实 Worker 转码完成；打开 HLS 播放、查看断点续播状态。只展示自己制作或可公开的测试媒体。
3. **公开分发（60 秒）**：打开创作者公开主页，再查看发现、关注流和日榜；强调 Redis 只提供候选/缓存，API 返回前由 MySQL 再验证当前可见性。
4. **互动与通知（60 秒）**：观众账号关注创作者、发表评论并回复；切到通知页查看未读/已读变化。重复点击仅验证幂等，不把重复操作说成多个独立互动。
5. **治理与审计（75 秒）**：以观众身份提交一个测试举报；管理员进入处置页分配、写理由并隐藏测试内容；打开审计记录确认操作者、状态变化和 request ID，再恢复内容。不要处置真实用户内容。
6. **故障回退与性能证据（60 秒）**：只对本地隔离 Redis 做停止/恢复演练，展示分类/榜单的降级行为；然后展示 [performance.md](performance.md) 的 5/10 VU API 基线和独立 HLS 分片结果，解释这些是固定本机合成数据下的可复现实验，不是生产容量结论。

如果不能在演示时间内等到真实转码完成，可预先完成一条自制短视频转码并在演示中重播结果；应明确这是预置结果，不把播放旧结果描述为刚刚完成的后台任务。结束后仅清理演示脚本明确创建的隔离测试视频，保留审计证据；不运行 `down -v` 或清理普通开发库。
